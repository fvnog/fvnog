### PLOX

- **Backend e dados:** PHP, Laravel, PostgreSQL, MongoDB, Redis, jobs assíncronos e Reverb/Echo.
- **IA e distribuição:** OpenAI API, Perplexity, Meta Graph API e WhatsApp/WPPConnect. Gestão de prompts, saída estruturada, retentativas e acompanhamento de uso e custos.
- **Automação:** Node.js, Playwright e Android/ADB, com controle de concorrência e recuperação de sessões.
- **Mídia e estúdio:** Intervention Image, Imagick, FFmpeg e Whisper; Python, OpenCV, MediaPipe e OBS WebSocket.
- **Operação:** Docker, Linux, Nginx e Cloudflare.

### Vitória

- **Aplicação:** PHP, Laravel, PostgreSQL, Blade, JavaScript, Tailwind CSS e Vite.
- **Integrações:** Sicoob API com OAuth 2.0 e mTLS; NF-e via Brasil NFe; WhatsApp com WAHA em Docker.
- **Documentos:** DomPDF, Tesseract OCR e Poppler. Pedidos, boletos, XML, DANFE e pacotes fiscais para a contabilidade.
- **Processos:** fichas técnicas, custos, fabricação, estoque, portal do cliente e operação de rotas e carga.

### AVN Sistemas

- **Aplicação:** PHP, Laravel, MySQL, Blade, JavaScript, Tailwind CSS e Vite.
- **Presença digital:** SEO técnico, sitemap, JSON-LD, Open Graph, imagens WebP e contato pelo WhatsApp.
- **Publicação:** Linux, Nginx e PHP-FPM, com releases versionadas e configurações e arquivos persistentes separados do código.
